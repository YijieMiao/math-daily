# Math Daily 微信小程序

在微信开发者工具中导入此目录。项目当前关联微信测试 AppID。公开发布需要换成正式小程序 AppID，在公众平台配置允许通过 wx.request 访问的 HTTPS 数据域名，再用真机验证并提交审核。当前数据源是 `https://yijiemiao.github.io/math-daily/data/`。若该域名无法登记，可使用已获微信认可的 HTTPS 域名镜像同一数据目录，并修改 data.js 的 dataBase。网页版链接仍可指向原站。

小程序支持多选研究方向、按批次浏览、搜索和收藏，AI 披露状态附原文证据和核查来源。比例以方向、搜索和收藏筛选后的论文为分母。发文量与 AI 披露占比可切换日、周视图。MathJax 3.2.2 置于异步分包，标题及摘要中的受支持公式转换为 SVG，无法排版时显示原始公式。

数据更新由现有 Math Daily 数据源提供。仅当线上请求失败时才回退到内置公告，并标明日期。收藏和方向选择保存在当前设备。
